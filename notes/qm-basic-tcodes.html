QM 기본 T-Code와 흐름 — 검사로트 · 결과 · 사용결정 · 품질통지

"입고했는데 왜 못 쓰지?"의 답을 한 장으로
대상: S/4HANA 기준 · 도해 3장 · 개인 프로젝트 범위 밖(비교·대비용)

결론부터. QM은 "검사로트 → 결과 → 사용결정"이고, 사용결정이 품질검사 재고를 풀어 주는 유일한 문입니다.

검사가 켜진 자재는 입고되자마자 품질검사 재고로 묶이고, QA11에서 합격(321)·보류(350)·폐기(553)로 나눠야 비로소 쓸 수 있게 됩니다.

LESSON 1QM 전체 지도 — 검사로트에서 사용결정까지

언제 보나. "입고했는데 재고가 안 보여요"라는 문의의 단골 원인이 QM입니다. 검사가 켜진 자재는 입고 즉시 쓸 수 없습니다.

핵심. QM은 검사로트 → 결과 → 사용결정 세 단계이고, 사용결정에서 재고를 어디로 보낼지 정합니다.

참고

개인 프로젝트(CL04)는 QM을 쓰지 않고 GATE 플랜트 + ZGATE_INSPECT(CBO)로 검수를 대신합니다. 표준 QM을 쓰면 무엇이 달라지는지 비교하는 용도로 읽으세요.

LESSON 2활성화 — 자재 QM 뷰 · 검사유형

언제 쓰나. 어떤 자재를 어떤 상황에서 검사할지 켜는 단계입니다. 이게 꺼져 있으면 검사로트가 생기지 않습니다.

1

자재마스터 품질관리 뷰(MM02) → 검사 설정(Inspection Setup) 버튼 → 검사유형 추가 · 활성 체크.

2

검사유형마다 옵션: 검사계획 사용 여부, 특성 기반 결과 기록, 샘플 계산 방식, 100% 검사 등.

3

플랜트 레벨 설정이라 플랜트마다 따로 켭니다 (QMAT).

검사유형언제 로트가 생기나이동유형

LESSON 5결과 기록 · 사용결정 — QE51N · QA11

언제 쓰나. 검사를 마치고 "이 로트 써도 되나"를 확정할 때입니다.

1

결과 기록 QE51N — 특성별 측정값 입력. 허용범위 밖이면 자동으로 불합격 표시.

2

사용결정 QA11 — 사용결정 코드(A 합격 / R 불합격) 선택.

3

재고 전기 — 같은 QA11 화면 "재고 전기" 탭에서 수량을 나눠 보냄. 저장 시 자재문서 생성.

반드시 지킬 것

1. 품질검사 재고를 311·344로 우회하지 않는다

사용결정 없이 재고를 옮기면 검사로트가 영원히 열린 채 남고 품질 이력이 끊깁니다. 반드시 QA11 재고 전기로.

2. 검사 활성화는 재고가 0일 때

품질검사 재고가 남은 상태에서 검사유형 설정을 바꾸면 기존 로트와 어긋날 수 있습니다.

3. 프로그램에서 사용결정은 BAPI로

BAPI_INSPLOT_SETUSAGEDECISION 등. QALS·QAVE 직접 수정 금지.
